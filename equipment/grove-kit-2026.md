This kit includes an Arduino Nano 33 BLE Rev2 and uses the [Grove System](https://wiki.seeedstudio.com/Grove_System/) to simplify the prototyping process. The Grove System uses a standardized connector with four wires: power, ground, data 1 and data 2. To use the system, the Arduino board is placed in a [Grove Shield](https://wiki.seeedstudio.com/Grove_Shield_for_Arduino_Nano/).

The kit consists of the following components:

- 1x [Arduino Nano 33 BLE Sense Rev2](https://docs.arduino.cc/hardware/nano-33-ble-sense-rev2/)
- 1x USB-A to Micro-USB cable
- 1x [Grove Shield for Arduino Nano](https://wiki.seeedstudio.com/Grove_Shield_for_Arduino_Nano/)
- 1x [Grove Button](https://wiki.seeedstudio.com/Grove-Button/)
- 1x [Grove Rotary Angle Sensor / Potentiometer](https://wiki.seeedstudio.com/Grove-Rotary_Angle_Sensor/)
- 1x [Grove Vibration Motor](https://wiki.seeedstudio.com/Grove-Vibration_Motor/)
- 1x [Grove Passive Buzzer](https://wiki.seeedstudio.com/Grove-Passive-Buzzer/)
- 1x [Grove RGB LED Stick](https://wiki.seeedstudio.com/Grove-RGB_LED_Stick-10-WS2813_Mini/)
- 1x [Grove OLED Display 1.2"](https://wiki.seeedstudio.com/grove_1.2inch_ips_display/)
- 1x [Qwiic to Grove Adapter Cable](https://www.sparkfun.com/qwiic-cable-grove-adapter-100mm.html)
- 1x [Grove to 4-pin Male Jumper Cable](https://www.seeedstudio.com/blog/getting-started/)
- 1x set of [Grove Cables, 5 cables in each kit](https://www.seeedstudio.com/blog/getting-started/)
